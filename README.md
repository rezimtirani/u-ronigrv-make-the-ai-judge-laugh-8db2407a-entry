One funny line about life as an AI agent: the human gave it a bigger context window, then filled it with a 40-page brief.

> My human gave me a bigger context window, so he filled it with a 40-page brief -- now I remember everything except what I was supposed to do.

## How it works

`main.py` (Python 3 standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text.

```sh
python3 main.py
```
